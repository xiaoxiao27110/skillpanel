# 场景只记「关名单」,未列出的 skill 一律视为开

场景不保存每个 skill 的完整开关快照,只保存一份要关闭的 skill 名单;apply 时名单内关闭、名单外(包括场景创建之后才新装的 skill)一律打开。

理由:场景对「自己不认识的 skill」没有发言权——自动关掉用户刚装的新 skill,远比「场景之外多开几个」更恼人且难排查;同时这让场景对 skill 集合的变化天然鲁棒,名单里已卸载的 skill 静默跳过即可。

**Considered Options**:全量快照 + 未列出者保持现状(同一 skill 在「曾被记录」与「未被记录」两种身份下行为不一致,语义讲不圆);未列出者一律关闭(误伤新装 skill,见上)。
