# 预设场景由部署层 seed,不进插件

SkillPanel 只提供用户自定义场景的存取与切换;「编码」「办公」这类预设由 Docker 部署配置在场景存储不存在时首次写入,对插件而言与用户自建场景毫无区别。

理由:预设作者(部署者)面对的是自己确定的 skill 集合,而插件面对任意用户机器——硬编码预设必然猜错 skill 名字。这一边界还顺带消灭了按模式匹配的需求:场景里只存精确 skill 名,不需要 glob,也不需要给 `SKILL.md` 加分类元数据。预设要改,改部署配置即可,不用给插件发版。

**Considered Options**:插件内置预设 + glob 匹配(跨机器匹配不可靠,且让插件背上它不该知道的 skill 知识);`SKILL.md` frontmatter 加 `category` 字段按分类匹配(依赖第三方 skill 作者配合,推不动)。
